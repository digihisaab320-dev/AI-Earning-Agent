# AI Earning Agent

A free-to-start, mobile-friendly AI work assistant for planning ethical online earning projects. This repository is independent and separate from DigiHisaab.

## Workspaces
- YouTube: ideas, scripts, titles and content plans.
- Android Apps: app ideas, feature planning and launch checklists.
- Digital Products: product outlines and practical sales plans.
- Freelancing: service ideas, proposals and portfolio plans.

## Run locally
Open `index.html` in a modern browser. For GitHub Pages, open this repository's **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save. Wait for GitHub Pages to publish the site.

## Connect Gemini
1. Create an API key in Google AI Studio: https://aistudio.google.com/app/apikey
2. Open the deployed page and enter the key in the API key field.
3. The key is kept only in the page's in-memory variable and is not saved to local storage or this repository. Refreshing the page clears it.
4. Never commit or share your API key. If you suspect it was exposed, revoke it in Google AI Studio and create another.

The app currently calls Gemini 2.5 Flash. Availability, quotas and free-tier terms are controlled by Google and may change. API access may require an eligible account or billing configuration.

## Important
